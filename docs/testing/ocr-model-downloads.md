# Загрузка языковых моделей OCR — v4

Настройки → Автономный (в браузере) → Языки OCR.
Кнопка «Скачать» устанавливает модель; после установки отметьте язык и нажмите «Сохранить».
Для японского скачайте 日本語 (jpn) и 日本語 (верт.) (jpn_vert), выберите их вместо eng/rus для японских страниц. Исходный язык — японский.

Доступны английский, русский, японский и вертикальный японский, упрощённый и традиционный китайский, корейский, немецкий, французский, испанский, итальянский. eng/rus входят в пакет; остальные скачиваются только вручную. Модели перевода не входят в эту функцию. С внешним Google-переводчиком распознанный текст отправляется Google.

Загрузка идёт с https://tessdata.projectnaptha.com/4.0.0_best/ по HTTPS после запроса разрешения только для этого сайта. Изображения сайту моделей не передаются. Файлы распаковываются и проверяются до сохранения; ограничения — 64 MiB сжатый, 128 MiB распакованный файл. Это структурная проверка файла, не криптографическая подпись. При отказе разрешения, ошибке сети или нехватке места модель не отмечается установленной. Автоматической загрузки нет.

Скачанные модели сохраняются отдельно от кэша переводов. После установки работают офлайн и доступны после перезагрузки страницы. «Удалить» удаляет скачанную модель, не встроенные eng/rus. После удаления выбранного языка нужно выбрать другой установленный язык. Удаление расширения удаляет и его хранилище; обновляйте существующую установку через ↻, не удаляйте её.

Установка обновления: замените содержимое прежней папки chrome-mv3 файлами из этого архива, нажмите ↻ в chrome://extensions и обновите настройки/страницу манги. Сохраняйте тот же путь папки расширения.

Проверено:
- 275 тестов / 29 файлов; TypeScript и production build прошли.
- Настройки реального расширения открыты в headless Chromium, desktop и 390 px, без ошибок страницы и горизонтального переполнения.
- Настоящий пакет jpn скачан с сервера моделей в тестовую среду. Production-загрузчик получил эти байты через подменённый сетевой ответ в Chromium, проверил и сохранил их. После перезагрузки страницы внешние запросы блокировались: production OCR прочитал модель из IndexedDB и распознал «こんにちは世界» (confidence 90). Удаление также проверено. Это тест реального Tesseract и хранилища, не полный тест интерактивного диалога разрешений в пользовательском Windows Chrome.
- Встроенный SIMD fallback использовался в проверке OCR.

Ограничения:
- Загрузка моделей не исправляет CORS на Rawlazy.
- Геометрия вертикальной манги и качество японского OCR на присланных страницах в этом обновлении не доказаны. jpn_vert теперь можно установить, но отдельная настройка вертикального конвейера ещё требуется.
- Это загрузчик OCR-моделей, не NMT/Opus-MT. Полностью офлайн японско-русский перевод здесь не добавлен.
- TeleOCR остался изолированным выключенным экспериментом.
- GitHub не обновлён; новые изменения не закоммичены. В архиве есть исходники, патч к восстановленному 0a47192 и исходный bundle восьми коммитов.
