# PicTranslate v3: проверка чистой страницы MangaDex

Дата: 2026-10-04. Оригинал предоставлен пользователем, PNG 1125×1600.

## Что действительно проверено

- Настоящий Tesseract.js и встроенные best-пакеты eng/rus из сборки расширения.
- Полностраничное распознавание с eng+rus, balanced, confidence 40, SPARSE_TEXT.
- Повторное OCR 13 кропов с eng+rus (прежняя политика) и eng (новая политика определения доминирующего алфавита).
- Production-хелперы предобработки, группировки, выбора языка, фильтрации, восстановления слов и маскирования.
- Визуальное размещение с production OverlayUI в headless Chromium: 5 плашек, 5 масок; текст помещается во всех пяти областях.
- npm test: 263 passed, 28 файлов; npm run compile и npm run build успешны.

Для Node применено безопасное LSTM-ядро без SIMD через тестовый адаптер: автоматический выбор SIMD в Node завершался ошибкой missing function DotProductSSE. Файлы установленных пакетов не изменялись. Для PNG/масштабирования кропов использован Sharp вместо браузерного canvas; растровые результаты не объявляются побитово идентичными Windows Chrome.

## Сравнение на этом примере

- Политика v2 сохраняла 13 групп, включая ложные pA, E SPAN, (1°, у, EM, a, &, И |.
- Политика v3 сохранила 5 диалоговых групп и убрала 8 шумных кандидатов.
- BECOME MY SUBOR- РТМАТ Е. → BECOME MY SUBORDINATE.
- YOUR SUBOR DINATE → YOUR SUBORDINATE: слитное написание подтверждено другой репликой этой же картинки, а не специальным словарём манги.
- I DON'T CARE сохранилось после повторного OCR. Отрицание терялось в первоначальном полном OCR, но уже восстанавливалось в повторном OCR v2; это не заявляется новым выигрышем v3.

## Непочиненные ограничения

- SETSUNA распознано как SETSLINA, в строке также остаётся лишний ~. Исправление собственных имён и всей пунктуации не гарантируется.
- Стилизованная надпись HE'S AN ENEMY, AFTER ALL!! остаётся в оригинале: некачественные фрагменты отфильтрованы, но её правильный перевод не реализован этой правкой.
- Пунктуация ...? под YOUR SUBORDINATE не вошла в исходные уверенные OCR-боксы; она остаётся на оригинальном рисунке.
- Фильтрация, определение алфавита и восстановление слов эвристические. На других страницах возможны пропуски настоящих коротких реплик.
- Маска закрывает текстовый прямоугольник, а не точно найденный контур речевого бабла; на сложном фоне она может задеть часть рисунка.
- Google/Groq не вызывались. В layout-preview.png русский перевод задан вручную только для проверки расположения и размеров текста. Этот снимок не доказывает качество машинного перевода.
- Полный end-to-end запуск расширения на живом MangaDex/Windows не проверен.

## Регрессионные доказательства

| Требование | Тест/проверка |
|---|---|
| Нет отдельных мусорных плашек в записанном примере | keeps five dialogues, restores the negation and repairs the evidenced split without artwork labels |
| Нет слепого склеивания любых слов | does not invent a spelling or join normal function-word phrases |
| Маска не заменяет настройку формы | uses a separate source rectangle mask while preserving the chosen oval frame |
| Исходный OCR доступен без выполнения HTML | shows OCR source and engine as inert text and replaces old diagnostics on retry |
| Ограничена дополнительная нагрузка | bounds crop work at sixteen and keeps later readable dialogue instead of silently dropping it |

## Повторная проверка на Windows

1. Заменить содержимое прежней папки chrome-mv3 новой сборкой; нажать ↻ в chrome://extensions.
2. Обновить вкладки настроек и манги. Удалять расширение и npm run vendor не нужно.
3. Режим: автономный в браузере; внешний переводчик Google, приоритет внешний; English → Russian; balanced; уверенность 40%; параллельность 1. Для этой манги достаточно языка OCR eng.
4. Повторить перевод страницы. В панели открыть «Показать распознанный оригинал», чтобы отдельно проверить OCR и перевод.

Новые результаты используют версию кэша v6-page-refinement; старые OCR-результаты не должны подставляться.
