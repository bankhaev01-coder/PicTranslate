# Проверка перевода страницы и видимой области

Ветка `feat/page-bubble-translation` от `5236e49`. TeleOCR в неё не входит.

## Что изменилось

- Локальные OCR-блоки объединяются в горизонтальные реплики по геометрии.
  В обычном браузерном OCR плотная линия между блоками запрещает объединение.
  Это эвристика, не нейросетевой детектор баблов; вертикальный японский не является
  целевым сценарием первой версии. Соседние пузыри иногда потребуют ручного выделения.
- Первые 16 групп повторно распознаются как кропы, последующие не теряются.
  Повторные проходы последовательны; они могут увеличить время OCR.
- Реплика переводится целиком один раз. Текст панели собирается из тех же ответов.
  Ошибка одного блока не подставляет туда перевод всей страницы; оригинал остаётся
  видимым. Частично неудачный результат не кешируется, чтобы повтор мог помочь.
- При наличии переведённых боксов общий текст не дублируется на тёмной плашке.
  Если боксов нет, старый fallback для изображения сохранён. При форме `none`
  пользователь по-прежнему получает только общий перевод.
- Перевод видимой области рисуется на странице по координатам кадра. Прокрутка
  после захвата сохраняет привязку к документу. Прокрутка во время захвата — ошибка;
  после изменения размера окна/масштаба нужен новый захват.
- Произвольная смена DOM/размера изображения без resize (например, динамическая
  перестройка сайта) может нарушить координаты кадра. Для таких страниц повторите
  захват. Сценарий `<img>` по-прежнему привязан к самому элементу изображения.
- Старые результаты скана/кадра не попадают в новый оверлей.
- Для Google/другого внешнего текстового MT не требуется скачанный Opus-MT.
- Добавлена кнопка настройки Groq через существующий Custom AI. Она не предоставляет
  разрешение, не отправляет изображения и не включает облачный OCR сама.

## Установка готовой сборки — Windows 10, Chrome/Edge

1. Распакуйте архив сборки; папка `chrome-mv3` содержит `manifest.json`.
2. Откройте `chrome://extensions` или `edge://extensions`.
3. Включите режим разработчика, выберите «Загрузить распакованное» и папку
   `chrome-mv3`. ZIP напрямую выбрать нельзя.
4. Не держите одновременно две активные версии расширения на одной странице.
   Для обновления прежней распакованной установки используйте прежний путь папки
   и кнопку обновления на карточке расширения; затем перезагрузите вкладку манги.
5. Сборка включает локальный Tesseract и языки `eng`, `rus`. Она не включает
   Opus-MT: полностью офлайновый перевод требует обычного полного vendor-пака.
   Внешний текстовый MT — отдельный явный выбор пользователя, а не часть офлайн OCR.

## Сначала проверить ваш нынешний режим

- Движок: «Автономный (в браузере)».
- Внешний переводчик: Google, предпочитать внешний.
- Исходный язык: English; целевой: Русский.
- OCR: только `eng`, качество сначала «Сбалансированный», уверенность около 40%.
- Форма перевода: прямоугольник или овал, не `none`; параллельность 1.
- «Облачное OCR выделенной области» необязательно. Как и раньше, эта галочка
  действует только на ручное выделение — не на страницу или видимую область.

Google MT получает распознанный текст; картинки ему этот локальный путь не отправляет.
Его неофициальный endpoint не имеет SLA и может ограничивать запросы.

Проверки на исходной странице пользователя:
https://mangadex.org/chapter/8495e01d-4e7c-4dd9-afa0-06d28759c30e/22

1. «Перевести изображение»: один логический текстовый блок должен получить один
   связный перевод, без огромного дублирующего прямоугольника слева при наличии боксов.
2. «Перевести видимую область»: переводы должны появиться непосредственно на странице,
   а не только в popup. После успешного ответа popup закрывается, панель остаётся.
3. Прокрутка: надписи следуют за тем же текстом. Изменение масштаба/ширины окна:
   устаревшие надписи кадра снимаются; нажмите перевод видимой области заново.
4. Повторный скан во время запроса: старые ответы не должны появляться в новой очереди.
5. Ручное выделение одного пузыря и Enter должны работать как раньше.

Снижение порога до 15% по-прежнему может добавлять рисунки/мусор. Группировка не
восстанавливает текст, который OCR вообще не обнаружил, и не гарантирует устранение
всех ошибок имён или стилизованных SFX.

## Groq — отдельный необязательный вариант

В настройках выберите AI и нажмите «Настроить Groq Vision (бесплатный тариф)».
Проверьте адрес `https://api.groq.com/openai/v1` и модель `qwen/qwen3.8-27b`.
Введите **свой** ключ Groq в парольное поле, нажмите «Разрешить доступ» к адресу,
затем сохраните. Ключ другого Custom AI автоматически не переносится.
Не вставляйте ключ в отчёт, скриншот или git.

Документация проверена 2026-10-04:
- https://console.groq.com/docs/vision
- https://console.groq.com/docs/rate-limits

Сервис получает изображения и текст только при вашем запуске перевода. Бесплатный
тариф ограничен; текущие лимиты смотрите в аккаунте. Платный fallback и автоматическая
смена аккаунтов/ключей не предусмотрены. Groq не тестировался живым API-запросом:
проверены настройка и совместимый формат клиента, не качество на этой манге.

OpenRouter уже был в проекте. Его бесплатные модели имеют свои квоты:
https://openrouter.ai/docs/limits — это не безлимитная замена Gemini.

## Сборка из исходников

Из каталога `extensions` (Node.js и npm уже должны быть установлены):

```bash
npm ci
npm run vendor:ocr
npm run compile
npm test
npm run build
```

`vendor:ocr` скачивает только языковые данные и копирует установленный Tesseract.
Его ассеты находятся в уже игнорируемых `public/` каталогах и не коммитятся.
Существующий полный vendor-пак не удаляется. Для локального Opus-MT по-прежнему
используется `npm run vendor` — он значительно тяжелее.

## Что подтверждено и что нет

Автоматические тесты проверяют группировку, границы, обработку ошибок, композицию
OCR/MT, DOM-отображение, маршрутизацию, устаревшие запросы и настройку Groq.
Проверка нового оверлея на синтетической странице не доказывает точность OCR манги.
Присланные скриншоты уже содержат переводы; использовать их как чистый OCR-эталон
нельзя. Скачать исходный файл MangaDex в проверочной среде не удалось: CDN вернул
HTTP 403. Живой сценарий этой страницы в пользовательском Chrome и качество
облачных моделей требуют проверки пользователем.

## Обновление v3: проверка на чистой странице

Повторный OCR кропов теперь учитывает доминирующий алфавит, не меняя сохранённые языки пользователя. Неуверенные фрагменты рисунка фильтруются; слитное слово может восстанавливаться по другой реплике этой же картинки. На светлом фоне используется отдельная маска исходного текста, а в панели доступен распознанный оригинал.

Результаты, методика настоящего OCR и непочиненные ограничения описаны в [manga-page-regression.md](manga-page-regression.md). Это не универсальный детектор баблов и не гарантия качества машинного перевода.
