# Архитектура и ключевые решения (ADR-01)

## 1. Контекст

Расширение переводит текст **на изображениях** (не на веб-странице): основной
сценарий — «перевести все изображения на странице сразу», вторичный —
инструмент выделения фигурой для повторного перевода проблемного участка.
Нейросети используются для OCR/распознавания (обычный «перевод картинок»
работает плохо), с возможностью работать **автономно** (локальный OCR) и
**подключать свою модель** через API.

## 2. Компоненты

```
┌─────────────────────────────── Chrome (MV3) ───────────────────────────────┐
│  popup (React)          options (React)        background (service worker) │
│  • скан страницы        • URL бэкенда          • роутер сообщений          │
│  • скриншот-перевод     • модель/языки         • инъекция скрипта (activeTab)│
│  • настройки            • проверка связи       • captureVisibleTab         │
│                                                • контекстное меню          │
│                                  │                                         │
│                     injected.ts (unlisted script, инжектится по требованию) │
│                     • скан <img> (min-size фильтр)                         │
│                     • Shadow-DOM панель + статусы + прогресс               │
│                     • ярлыки перевода над картинками                       │
│                     • инструмент выделения (rect) → кроп → повторный запрос│
└────────────────────────────────────┬───────────────────────────────────────┘
                                     │ HTTP POST /translate (multipart)
                                     ▼
┌─────────────────────────────── backend (FastAPI) ──────────────────────────┐
│  api/translate  ── кэш (sha256 изображения) ── очередь (bounded concurrency)│
│  models/registry ──► tesseract | openai | gemini | custom (ваша модель)    │
│  translator      ──► текстовый перевод для local-OCR пути                  │
│  cache: Redis → fallback file-cache                                        │
└────────────────────────────────────────────────────────────────────────────┘
```

### Почему так

| Решение | Причина |
|---|---|
| WXT + React + TS | Vite-сборка, MV3 из коробки, типизация, HMR |
| Unlisted script вместо content script на `<all_urls>` | Инъекция по `activeTab` только после действия пользователя → минимальные permissions и мягкое предупреждение при установке |
| Бэкенд обязателен | API-ключи нельзя хранить в расширении; бэкенд — прокси и кэш; модель легко заменить |
| Tesseract в Docker-образе | Офлайн-автономность без облачных ключей |
| Абстракция `ModelAdapter` | Подключение своей нейросети — новый адаптер, без правок API |

## 3. Поток данных

### 3.1 Основной: «все изображения сразу»

1. Пользователь нажимает иконку (popup) или ПКМ → «Translate images on this page».
2. Background **инжектит** `injected.js` в активную вкладку (activeTab) и шлёт `SCAN_IMAGES`.
3. Скрипт сканирует `<img>` (порог `minImageSize`, только видимые/крупные), строит список.
4. На странице появляется панель (Shadow DOM): список картинок + статусы + прогресс.
5. Пользователь нажимает «Перевести все» → для каждой картинки (конкурентность ≤ 3):
   - `fetch(src)` → Blob → dataURL (same-origin/CORS);
   - `TRANSLATE_DATA_URL` → background → `POST /translate`;
   - ответ (перевод) → строка в панели + ярлык над картинкой.
6. Если `fetch` запрещён (CORS) — статус «error» с подсказкой использовать скриншот-режим.

### 3.2 Вторичный: коррекция фигурой (инструмент выделения)

1. В панели — «Выделить область» → оверлей-слой с crosshair.
2. Пользователь рисует прямоугольник (MVP: rect; архитектура готова к circle/freeform).
3. Скрипт запрашивает `CAPTURE_VISIBLE` (background → `captureVisibleTab`),
   вырезает регион через canvas (учёт `devicePixelRatio`) → `region_only=true`.
4. Бэкенд кэширует отдельно (`reg:` префикс ключа) и возвращает перевод участка.
5. Результат — всплывающий ярлык у выделенной области (живёт 15 с).

### 3.3 Скриншот-перевод (popup)

`CAPTURE_AND_TRANSLATE`: background делает скриншот видимой области и сразу
отправляет в `/translate`; результат показывается в popup. Покрывает случаи,
когда картинку нельзя прочитать из DOM (PDF-viewer, canvas, CORS).

## 4. Модели: сравнение и выбор

| Вариант | Плюсы | Минусы | Когда использовать |
|---|---|---|---|
| **Tesseract (локально, Docker)** | Бесплатно, офлайн, без ключей, предсказуемая задержка | Нужен preprocessing, хуже на манге/сложных шрифтах | Режим автономности, приватность |
| **OpenAI Vision (GPT-4o)** | OCR+перевод за один вызов, отличное качество | Платно, ключ, картинка уходит в облако | Максимальное качество |
| **Gemini Vision** | Альтернатива OpenAI, гибкие тарифы | Аналогичные ограничения | Если удобнее Google-стек |
| **Custom API** | Полный контроль, любая своя модель/файн-тюн | Ответственность за качество и хостинг | Собственная нейросеть |
| **Pollinations (расширение, напрямую)** | Бесплатный OpenAI-совместимый vision (`gen.pollinations.ai`, модель `openai` = GPT-5.4-nano) | Для изображений обязателен бесплатный ключ (`enter.pollinations.ai/keys`); анонимный tier принимает только текст. Легаси-эндпоинт `text.pollinations.ai/openai` deprecated и vision не поддерживает | Дешёвый AI без своего бэкенда |

Роутинг: `model` из запроса → `DEFAULT_MODE` из `.env` → `tesseract` (безопасный офлайн-фолбэк).
Алиасы: `local|ocr|offline → tesseract`, `cloud|vision → openai`.

## 5. Безопасность и приватность

| Аспект | Решение |
|---|---|
| **API-ключи** | Только на бэкенде (`backend/.env`, не в git). Расширение хранит лишь выбор модели и языки — несекретно. |
| **Permissions** | `activeTab`, `storage`, `scripting`, `tabs`, `contextMenus`. `host_permissions` — только `localhost/127.0.0.1`. **Нет `<all_urls>`** ни в content scripts, ни в host_permissions. |
| **Инъекция** | Unlisted script по `activeTab` — только после клика пользователя по текущей вкладке. |
| **CORS** | Бэкенд разрешает `chrome-extension://*` и локальные origin'ы (`ALLOWED_ORIGINS`). Не использовать `*` в проде. |
| **Приватность** | Офлайн-режим (Tesseract) — изображения не покидают машину. Облачные модели — предупреждение в Options; картинки уходят только на **ваш** URL бэкенда. |
| **Кэш** | Ключ — SHA-256 изображения; содержимое изображений не логируется. |
| **Лимиты** | `MAX_IMAGE_BYTES` (413 при превышении), таймауты на OCR/перевод, `max_concurrent_tasks`. |
| **HTTPS / WSS** | Манифест даёт быть `http://localhost` (Dev). Для прода — использовать HTTPS-домен и обновить `host_permissions` и `ALLOWED_ORIGINS`. |

## 6. MVP: что входит и критерии готовности

### Объём MVP

- Скан страницы и панель «все изображения сразу» с прогрессом и статусами.
- Перевод каждого изображения через бэкенд: `tesseract` (офлайн) **и** `openai` (облако).
- Кастомный адаптер (ваша нейросеть) с конфигом URL/ключа.
- Инструмент выделения **rect** → повторный перевод региона (коррекция).
- Скриншот-режим в popup (видимая область).
- Кэш переводов (Redis/file) — повторные запросы бесплатны.
- Очередь с ограничением параллелизма.
- RU/EN интерфейс (i18next), манифест локализован (`_locales`).
- Docker Compose: бэкенд + Redis одной командой.

### Критерии готовности (проверено)

- [x] `npm run build` (wxt) — **exit 0**, артефакт `dist/chrome-mv3` (~290 KB).

- [ ] E2E Playwright (следующая итерация).

### Что осталось за MVP (roadmap)

1. **Circle / freeform** выделение с маской (сейчас — rect).
2. **Автоскан** при загрузке страницы (`autoScan` есть в настройках — не подключён к слушателю вкладок).
3. **Полный скриншот страницы** (scroll-stitch) для длинных pdf/манги.
4. **EasyOCR** адаптер (качество на CJK/манге) и батчевый inference своей модели.
5. **История переводов** в IndexedDB + экспорт.
6. **E2E Playwright** + ESLint/Prettier конфиги.
7. **Аутентификация бэкенда** для публичного хостинга (сейчас — локальный сервис).

## 7. Как добавить свою нейросеть (custom-адаптер)

Ожидаемый контракт (см. `backend/app/models/custom_adapter.py`):

```
POST <CUSTOM_API_URL>
Authorization: Bearer <CUSTOM_API_KEY>        # опционально
multipart/form-data:
  image       → file (png/jpeg)
  target_lang → str            # 'ru'
  source_lang → str            # 'auto' | 'en' | ...
  return_boxes→ 'true'
→ JSON:
  { "translation": "...", "source_text": "...", "detected_language": "en", "boxes": [] }
```

Достаточно указать `CUSTOM_API_URL` и `CUSTOM_API_KEY` в `backend/.env` и выбрать
модель `custom` в настройках расширения.
